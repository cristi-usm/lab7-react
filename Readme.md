# 💪 Workout Planner

O aplicație React pentru crearea unui plan de antrenament personalizat, construită ca formular multi-step cu vizualizare live.

## Demo

[workout-planner-weld.vercel.app](https://workout-planner-weld.vercel.app)

## Funcționalități

- Formular în 4 pași: date personale, antrenamente, exerciții și recapitulare
- Validare completă cu mesaje de eroare
- Preview live al datelor introduse
- Reset complet al formularului

## Tehnologii

- React + Vite
- Context API + useReducer
- CSS Modules
